# Hypercalc Artifacts

Created (UTC): 2026-04-28T00:26:00Z

Repository HEAD: dad97d346dba0cc2ef8655f3527cb5fc37f61b72

This directory contains local Hypercalc artifacts. Hypercalc is important to
Nummy because it is a practical power-tower calculator lineage that predates
the incremental-game libraries and directly models the "avoid overflow by
raising the representation level" idea.

## Files

- [`hypercalc.perl`](hypercalc.perl) - Perl Hypercalc source; the local file
  header identifies it as Robert P. Munafo's 2026 Jan 01 version.
- [`hypercalc-javascript.html`](hypercalc-javascript.html) - HTML/JavaScript
  calculator page by Robert P. Munafo and Kenny TM~ Chan.

## Notes

The Perl and HTML files carry their own copyright and licensing statements in
file headers. Keep those headers intact. The local purpose of these artifacts is
algorithm study: parsing notation, normalizing power-tower values, comparing
operation behavior, and understanding uncertainty/error propagation choices.
