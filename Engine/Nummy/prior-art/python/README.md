# Standalone Python Experiments

Created (UTC): 2026-04-28T00:26:00Z

This directory groups loose Python files that are useful for Nummy source
study but are not packaged as independent projects.

## Files

- [`break_eternity.py`](break_eternity.py) - compact Python experiment using a
  sign/magnitude/layer-style representation inspired by break_eternity.
- [`hypernums.py`](hypernums.py) - Python `Hypernum` class modeled after
  Robert Munafo's Hypercalc power-tower representation.

## Usage Guidance

These files are best read as sketches and behavior references. If either one
becomes the basis for a maintained Nummy component, copy the relevant ideas into
`../../src/` with explicit licensing review and tests instead of growing this
directory into production code by accident.
