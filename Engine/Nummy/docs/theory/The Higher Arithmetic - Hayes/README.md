# The Higher Arithmetic (Hayes)

This directory contains Brian Hayes's "The Higher Arithmetic", a popular
article about huge-number arithmetic and alternatives to conventional
floating-point representation.

## Files

- [Markdown rendering](<The Higher Arithmetic - Hayes.md>) - generated from the TeX sidecar for easier reading and search.
- [TeX sidecar](<The Higher Arithmetic - Hayes.tex>) - searchable OCR/LaTeX source used to generate the Markdown rendering.
- [`images/`](images/) - extracted figures referenced by the TeX sidecar.

## Why It Matters

The article is the most accessible entry point in this corpus. It connects
ordinary bignums, tapered floating point, logarithmic systems, and
level-index arithmetic in a way that is useful before reading the denser
Clenshaw/Olver/Turner papers.
