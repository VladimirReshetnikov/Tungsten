## Why It Matters

The symmetric system adds the sign/reciprocal machinery needed to represent
negative values and tiny magnitudes while preserving the core level-index
mapping. Its algorithm and error-control sections are especially relevant for
any future Nummy representation that wants a principled alternative to ad hoc
layer/magnitude arithmetic.
