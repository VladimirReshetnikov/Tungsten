This directory contains the broad survey "Level-Index Arithmetic - An
Introductory Survey" associated with the Lancaster Numerical Analysis Summer
School material. It is the best single source here for understanding how
level-index arithmetic compares with other alternatives to floating point.

- [Markdown rendering](<Level-Index Arithmetic - An Introductory Survey - Clenshaw 1989.md>) - generated from the TeX sidecar for easier reading and search.
- [TeX sidecar](<Level-Index Arithmetic - An Introductory Survey - Clenshaw 1989.tex>) - searchable OCR/LaTeX source used to generate the Markdown rendering.
- [`images/`](images/) - extracted figures referenced by the TeX sidecar.

## Why It Matters

The survey connects the motivation, precision model, closure properties,
operation costs, and implementation options for LI and SLI arithmetic. It also
discusses application areas such as binomial probability distributions and
root-squaring, making it the main bridge between the theoretical papers and
prototype implementation decisions.
