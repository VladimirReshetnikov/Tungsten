This directory contains Eberhard Zehendner's German lecture handout on
computer arithmetic. In the Nummy corpus it provides secondary context around
logarithmic number systems, tapered floating point, level-index arithmetic, and
dynamic number formats.

## Files

- [PDF](<Rechnerarithmetik.2008.09.handout.pdf>) - authoritative handout copy.
- [Markdown rendering](<Rechnerarithmetik.2008.09.handout.md>) - generated from the TeX sidecar for easier reading and search.
- [TeX sidecar](<Rechnerarithmetik.2008.09.handout.tex>) - searchable OCR/LaTeX sidecar named to match the PDF.

## Why It Matters

The handout places LI/SLI beside neighboring number-system ideas. It is useful
when evaluating whether a Nummy design should resemble a logarithmic number
system, a tapered format, or a power-tower/level-index representation.
